## Chess Data Mining & Pattern Analysis

A data mining project analyzing thousands of chess games to investigate
game outcomes, player performance, opening patterns, and rating
distributions.

### Key Work

- Cleaned and analyzed 5,854 chess games
- Investigated player Elo distributions
- Analyzed game outcomes
- Examined chess opening patterns
- Applied FP-Growth association rule mining
- Performed statistical analysis using chi-square testing
- Built an SQLite data warehouse
- Created data visualizations using Python

### Technologies

Python Pandas Matplotlib Seaborn mlxtend SQLite Jupyter Notebook SQL
